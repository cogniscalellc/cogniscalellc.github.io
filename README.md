# Cogniscale

Public website for Cogniscale LLC, an independent software product studio.

Live site: [cogniscalellc.github.io](https://cogniscalellc.github.io)

## Files

- `index.html` - semantic page content
- `styles.css` - responsive layout and visual system
- `favicon.svg` - Cogniscale mark
- `.nojekyll` - direct GitHub Pages publishing

## Preview locally

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
